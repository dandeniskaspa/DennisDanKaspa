# DennisDanKaspa

A [Remotion](https://www.remotion.dev/) video project.

## Getting Started

```bash
npm install
npm run dev        # open Remotion Studio at http://localhost:3000
```

## Rendering

```bash
npx remotion render HelloWorld output.mp4
```

## Claude Code Skills

This project includes a `remotion-dev` skill for Claude Code. Type `/remotion-dev` to get help with common Remotion development tasks (starting the studio, adding compositions, rendering, animations).
